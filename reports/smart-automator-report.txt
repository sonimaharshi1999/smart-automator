======================================================================
  SmartAutomator - Adaptive API/UI Automation Framework
======================================================================

Author: Maharshi Soni
Category: qa-ai-automation
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
Intelligent automation framework that auto-selects between API calls and UI automation. Three script generation modes: prompt-based, screenshot-based, and recording-enhanced. No POM — AI dynamically generates resilient label-based XPath selectors. Includes humanizer layer and self-healing on selector failure.

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * API/UI hybrid strategy selector
  * Prompt-to-script generation
  * Screenshot-to-selector generation
  * Recording enhancement with AI
  * Self-healing selectors
  * Humanizer (Bezier mouse, Gaussian delays, realistic typing)
  * Cron scheduler
  * Platform registry with YAML configs

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Natural language automation request

  Example:
    smart-automator run --workflow linkedin_post.yaml --content 'Excited about my new project'

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Automation execution results

  Example:
    Strategy: UI (no API available) | Generated 5 action steps | Executed in 12.3s | Status: SUCCESS
